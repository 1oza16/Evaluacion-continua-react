# Tres en Raya (Tic-Tac-Toe) en React

Juego clásico de **Tres en Raya** desarrollado con **React** y **Vite**, con diseño e interfaz retro estilo Bauhaus / Neo-brutalismo.

---

## ¿Qué hace el proyecto?

- **Partidas interactivas:** Alternancia por turnos entre jugador **X** y jugador **O**.
- **Detección de ganador:** Calcula automáticamente si hay un ganador tras cada jugada o notifica el siguiente turno.
- **Historial de movimientos ("Viaje en el tiempo"):** Guarda el estado de cada jugada permitiendo volver a cualquier movimiento anterior de la partida.
- **Diseño personalizado:** Estilos limpios y llamativos en CSS con estética Bauhaus (bordes sólidos, sombras marcadas y paleta de colores primaria).

---

## Cómo ejecutar el proyecto

1. **Instalar dependencias:**
   ```powershell
   npm install
   ```

2. **Iniciar el servidor de desarrollo:**
   ```powershell
   npm run dev
   ```

3. **Abrir en el navegador:**
   - La consola indicará la URL local (usualmente [http://localhost:5173/](http://localhost:5173/)).
